# PilahAI — Asisten Pemilahan Sampah Cerdas ♻️

PilahAI adalah aplikasi web interaktif berbasis AI yang membantu memilah dan mengklasifikasikan sampah secara cerdas menggunakan Google Gemini AI Vision.

## ✨ Fitur Utama
- **Deteksi Cerdas**: Identifikasi jenis sampah (Organik, Anorganik, B3, Residu) melalui foto/kamera secara real-time.
- **Rekomendasi Penanganan**: Panduan cara memilah, mendaur ulang, atau membuang sampah dengan benar.
- **Nilai Ekonomi & Bank Sampah**: Informasi potensi nilai jual daur ulang dan estimasi poin ramah lingkungan.
- **Interface Modern & Responsif**: Dibangun dengan Tailwind CSS dan desain interaktif yang nyaman digunakan di perangkat desktop maupun mobile.

## 🚀 Cara Menjalankan
1. Clone repositori ini:
   ```bash
   git clone https://github.com/Ap3lll/Trash.git
   ```
2. Buka file `index.html` langsung di browser Anda (atau gunakan ekstensi Live Server di VS Code).
3. Masukkan Gemini API Key Anda pada pengaturan aplikasi untuk mengaktifkan fitur analisis foto cerdas.

## 🛠️ Teknologi
- HTML5 & CSS3
- Tailwind CSS
- JavaScript (Vanilla)
- Google Gemini API (Multimodal Vision)
